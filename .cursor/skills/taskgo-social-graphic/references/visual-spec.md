# 匠管 TaskGo FB／IG 視覺規格

對齊原帳號圖文：專業工地管理 × 數位工具，接地氣、有台灣節慶與案場文化。

## 色票

| 角色 | 色碼 | 用法 |
|---|---|---|
| 海軍藍 | `#0B2D5C` | 主底、斜切字塊、半透明疊圖 |
| 青藍 | `#2BA3D6` | 層次、蜂巢紋、輔助色塊 |
| 白 | `#FFFFFF` | 留白、系統畫面卡 |
| 安全橘 | `#ED9121` | 主標局部、工安強調（不當大面積底） |
| 黃 | `#F7B500` | 同橘，點題用 |
| ESG 綠 | 僅環境議題 | 不要當日常主色 |

短影音阿豪主色仍是橘；本規格只管 FB／IG 圖文。

## 構圖

- 斜切平行四邊形 banner，不要四平八穩矩形堆疊
- 工地實拍上疊半透明海軍藍，白字才讀得清
- 淡青六角／蜂巢紋，點出「數位、可複製」
- 可對角分割：一邊塔吊／師傅／平板，一邊深藍字塊
- 吉祥物從邊角落出，指向主標

## 人物與道具

- 台灣工班：白或黃安全帽、反光背心、深藍工作服
- 東亞臉、自然身形，表情務實，不要歐美模特假笑
- 手裡常有平板、手機 LINE、藍圖、捲尺
- 阿豪人設只在講工班師傅性格時用，不要每張都放臉

## 藍色機器人吉祥物

圓頭、大圓眼、短天線；可戴藍安全帽或拿鉛筆。是 AI 幫手，不是卡通主角，不要日式大眼萌、不要佔畫面一半。

## 台灣文化錨（每張至少一個，可淡）

| 時機 | 畫面 |
|---|---|
| 開工／過年後 | 案場紅布條、春聯、開工 |
| 端午 | 工地粽、安全帽旁的粽 |
| 中元 | 普渡、工安祈福（不獵奇、不恐怖） |
| 颱風 | 收工、帆布、積水巷口 |
| 日常 | 大台北塔吊、騎樓整修、LINE 群、工務所茶桶 |

用語：工班、案場、師傅、頭仔、匠管。不要中國用語。

## 圖上文字

- 只寫正確台灣繁體中文
- 主標 4–10 字，可局部黃字
- 整張文字元素不超過 5 個（主標 + 最多 3 句短語 + 1 個 2–4 字 UI 標）
- 不要簡體、不要英文亂碼、不要自己畫 TaskGo／INFORCRAFT logo

## 系統畫面

素材庫的後台截圖不能原圖直發。要做成海報：痛點主標 → 工班現場煩惱 → 平板／白卡只露出這張畫面的一個重點功能。

## 禁止

- 整頁系統截圖置中鋪在海軍藍或純色底上
- 深灰或米白大字語錄卡當主視覺
- 歐美工地棚拍、金色夕陽懷舊底片風
- 電商促銷感、保險 DM、傳統房仲海報
- 政治、宗教對立、工安傷亡獵奇

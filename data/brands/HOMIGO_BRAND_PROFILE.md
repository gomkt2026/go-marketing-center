> **版本**:v1.0(2026-08-07)
> **安全聲明**:本檔案不含任何帳號、密碼、API Key、Token、資料庫連線資訊等機敏資料,可安全提供給外部系統使用。

## 1. 品牌總覽

### 1.1 品牌名稱與定位

| 品牌 | 定位 | 一句話說明 |
|------|------|-----------|
| **Homigo** | 主品牌 | 建立在 LINE 上的智慧租屋管理平台,讓房子自己運作 |
| **TaskGo** | 修繕生態夥伴 | 修繕媒合與工班派工平台,已與 Homigo 深度串接 |
| **Washgo** | 生活服務入口 | 洗衣到府收送服務整合,租屋生活加值服務之一 |

### 1.2 核心 Slogan

- 主 Slogan:**「不是管理房子,而是讓房子自己運作。」**
- 副標:整合 LINE Bot 與 AI,幫房東自動化收租、合約、報修與通知,**讓你每天只需要看一眼**。
- TaskGo 串接主張:**「重新定義包租代管的修繕管理流程」**
- 品牌承諾:**更有效率 · 更透明 · 更值得信任**
- 收尾語:「讓你的房子,開始自己運作。」

### 1.3 品牌信念

> 真正好的租屋管理,不是收租而已,
> 而是讓每一件事情都有完整的流程與紀錄。

## 2. 品牌價值主張(Value Proposition)

### 2.1 對房東 / 包租代管業者

1. **免下載 App,LINE 就能管房**:LIFF 登入 + Rich Menu + 推播通知,零學習門檻。
2. **全生命週期一條龍**:招租 → 簽約 → 入住點交 → 收租 → 報修 → 退租 → 再招租,單一平台完成。
3. **每天只看一眼**:每日待辦摘要主動推送(收租、續約、報修),不用自己記。
4. **修繕不再靠 LINE 群追進度**:TaskGo 串接,一鍵找師傅、詢價比價、派工、施工進度照片同步。
5. **自動對帳**:銀行交易與租金 / 電費自動匹配,逾期自動催繳。
6. **三種身分一個帳號**:自管房東(OWNER)、代管業者(MANAGER)、包租業者(OPERATOR)視角切換。

### 2.2 對房客

1. **報修有下文**:報修後可即時查看處理方式與施工進度,不用一直問房東。
2. **繳租留紀錄**:繳租上傳、審核、歷史紀錄查詢,租屋帳務透明。
3. **好房客被看見**:雙向評價 + HomiScore 信用分數 + 徽章任務,累積租屋信用資產。
4. **租屋生活服務**:洗衣收送(Washgo)、生活修繕、叫車、訂餐等加值服務入口。

### 2.3 差異化優勢(競品對比敘事)

| 傳統做法 | Homigo 做法 |
|---------|------------|
| Excel + LINE 群組手動管理 | 系統化流程,全程留痕 |
| 報修靠 LINE 找工班、來回傳照片 | 一鍵媒合 TaskGo、進度同步 |
| 對帳靠手抄存摺 | 銀行交易自動匹配租金 |
| 房客信用無從查證 | HomiScore 雙向評價體系 |
| 要下載又一個 App | LINE 原生,打開就能用 |

## 3. 產品功能地圖(供貼文取材)

### 3.1 Homigo 主平台

- **物件管理**:物件建檔、分群、公開刊登、空房雷達、投報率(ROI)分析
- **租約管理**:建立 / 續約 / 終止、電子簽名、房規設定、共同承租人
- **租金帳務**:繳租上傳審核、自動催繳、水電表管理、財務報表
- **點交作業**:入住點交、退租 SOP、設備檢查清單
- **報修流程**:房客報修 → 房東決策(找師傅 / 自己安排 / 房客自修 / 暫不處理)→ 派工 → 完工確認
- **信用生態**:雙向評價、HomiScore、徽章任務、排行榜、HomiCoin 點數商城
- **指揮中心**:戰情室總覽、異常事件提醒、維修 / 收租 / 資產地圖、任務日曆
- **AI 功能**:AI 招租文案生成、空屋一鍵換裝(虛擬佈置)、收據 / 電表 OCR 辨識、AI 智慧尋屋配對
- **每日摘要**:LINE 每日推播房東待辦(收租、續約、報修),支援三種營運視角

### 3.2 TaskGo 串接(修繕生態)

- 房客報修後,房東可**一鍵找師傅**,直接串接 TaskGo 修繕市集
- 兩種派工路徑:**直接指定廠商** 或 **公開詢價比價**(認證組織 / 個人師傅)
- 派工後**四階段施工進度 + 照片同步**,房東房客看同一組狀態
- 案號、階段、報價金額一目了然,全程留痕
- **生活修繕**:不綁租約也能建單,自費使用同一套修繕管線
- 市場定位:**依 Homigo 市場調查,為包租代管軟體首創的 TaskGo 串接**

### 3.3 Washgo(洗衣服務)

- 定位:**到府收送 · 專業精洗 / 精緻洗護**
- 房客 / 房東從 Homigo「增值服務」進入,選擇合作洗衣品牌預約
- 敘事角度:租屋生活不只有繳租報修,Homigo 把生活服務也接進來

## 5. 語調與文案風格指南(Tone of Voice)

### 5.1 整體語調

- **語言**:繁體中文(台灣用語)
- **性格**:專業但不生硬、有溫度、務實、可信賴
- **核心語感**:少講技術、多講「省心」「透明」「留痕」「一條龍」的生活感
- **避免**:誇大不實(「保證」「100%」「最便宜」)、恐嚇式行銷、貶低競品

### 5.2 常用關鍵訊息(Key Messages)

1. 「不是管理房子,而是讓房子自己運作。」
2. 「每天只需要看一眼。」
3. 「房客報修後,不用再靠 LINE 找工班。」
4. 「從報修到派工,流程完整留痕。」
5. 「房客、房東、指揮中心,看同一組狀態。」
6. 「好的租屋管理,是讓每件事都有完整的流程與紀錄。」
7. 「免費開始,不綁信用卡。」

### 5.3 各平台調性差異

| 平台 | 受眾傾向 | 調性 | 格式建議 |
|------|---------|------|---------|
| **Facebook** | 房東、代管業者(35+) | 完整敘事、專業可信 | 長文 + 輪播圖卡,痛點 → 解法 → CTA |
| **Instagram** | 年輕房東、房客(25~40) | 視覺優先、生活感 | 4:5 痛點主標(1080×1350)、前 125 字完整 hook、搜尋打標籤 |
| **Threads** | 租屋族、科技關注者 | 口語、短、敢聊時事 | 短文 1~3 段,可蹭租屋話題、開放留言互動 |
| **X(Twitter)** | PropTech / 科技圈、國際視野 | 精煉、觀點型 | 單則重點 + thread 展開,可中英混用 |

### 5.3.1 Instagram 操盤規則（產圖與文案）

- **第一句決定推薦**：前 125 字（摺疊前）必須是完整痛點 hook，與圖上 4–10 字主標同義。
- **搜尋打標籤**：每篇只對準一個顧客會搜的詞（包租代管／房東報修／收租對帳／租屋合約管理／代管系統）。
- **帳號辨識 > 單篇爆款**：米白底、深藍資訊、黃強調；寧可穩，不要為了爆款換成不像 Homigo 的風格。
- **推薦資格**：不洗 hashtag、不標題黨、不互動勒索。Hashtag 8–12 個。
- **產圖**：4:5 直式；B 端優先社群設計圖（痛點主標 → 情境 → 系統畫面卡）。

## 7. 事實邊界(Fact Boundaries)— 生成內容不可逾越

1. **可宣稱**:「依 Homigo 目前市場調查,為包租代管軟體首創的 TaskGo 串接」— 必須帶「依 Homigo 目前市場調查」前提
2. **不可宣稱**:市佔率第一、用戶數字(除非另行提供官方數據)、「保證」性承諾
3. **未上線功能不可當作現有功能宣傳**(如:社會住宅資訊功能為「即將推出」)
4. **價格敘述**僅限:「免費開始,不綁信用卡」,不得自行編造方案價格
5. **TaskGo / Washgo 為合作生態夥伴**,不可宣稱為 Homigo 自有品牌
6. 不得生成任何暗示可規避法規(如逃漏稅、違建出租)的內容

## 10. 給行銷平台的生成指令建議(System Prompt 素材)

生成每篇貼文時,請遵循:

1. 從「內容支柱」選定一個主題,結合當週網路熱度話題(若適用)
2. 依目標平台套用「各平台調性差異」的格式與語氣
3. 內文至少包含一個「常用關鍵訊息」或其變體
4. 結尾附上對應平台的 CTA 與 3~8 個 Hashtag
5. 全文檢查是否違反「事實邊界」任何一條
6. 語言一律使用繁體中文(X 平台可視受眾中英混用)

# GO 行銷中心 — 操作手冊（品牌經營者）

## 登入

1. 開啟 GO Marketing Center 網址
2. 輸入管理員帳號與密碼（由維運人員提供）
3. 登入成功後可看到所有品牌（上帝視角）

> **注意**：目前為單一共用管理員帳號，所有操作在系統中皆記錄為該帳號所為。

## 品牌切換

- 使用左上角 **品牌切換器** 選擇 Homigo / TaskGo / Washgo
- 切換品牌時，若目前在品牌專屬頁面，URL 會同步更新
- 選擇「全部品牌」可回到跨品牌總覽

## 主要流程

### 1. 總覽 Dashboard
- 查看待決策提案、待審閱內容、最新市場情報
- 點擊各品牌卡片進入品牌工作區

### 2. 品牌智慧
- 瀏覽品牌核心、受眾、平台調性、規則邊界
- **規則邊界**分頁可新增/封存規則（寫入資料庫並留 activity log）
- **品牌核心**可登記官方網站,寫進該品牌資料
- **EDM／簡報**分頁可上傳各品牌 EDM 或產品簡報(PDF／PPT);系統抽出賣點後,可產出給客戶的 LINE 訊息(含檔案連結與官網),排程社群文也會引用

### 3. 市場情報
- 查看 AI 蒐集的市場信號
- 可將新信號標記為「討論中」或「忽略」

### 4. AI 會議室
- 左側選擇會議，右側查看 AI 討論紀錄
- 管理者可在底部輸入框插話（寫入資料庫）

### 5. 決策中心
- 查看 AI 提案（方案 A/B/C）
- **批准 / 退回 / 否決** — 所有決策寫入資料庫並記錄操作者

### 6. 內容中心
- 依狀態分類審閱內容
- 批准、修改、退回、否決等動作會寫入 `content_reviews`

### 7. 時間軸
- 查看全流程 activity log
- 可依品牌篩選

## 登出

- 點擊右上角 **登出** 按鈕

# 業主查看專案

## 我要怎麼登入看工程進度？
1. 打開廠商給你的業主登入頁
2. 輸入 Email 與密碼
3. 按登入
4. 進入專案列表

帳號由施工廠商建立。沒有帳號請直接問對方，不要用員工後台帳號登入。

## 登入後要去哪裡看進度？
專案列表點進該案，可看進度、任務狀態、工期與完工照片。

## 我可以看到報價成本嗎？
看不到成本明細、內部備註、員工薪資與廠商資訊。這些只有施工廠商後台看得到。若要報價內容，請對方另傳報價簽名連結。

## 忘記密碼怎麼辦？
請聯絡幫你開帳號的施工廠商重設，這個入口沒有自行註冊。

## 為什麼看不到某個案子？
廠商尚未把該專案授權給你的帳號。請對方在客戶帳號裡勾選該專案後，你再重新整理頁面。

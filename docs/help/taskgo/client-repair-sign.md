# 報價與驗收簽名

## 報價單要怎麼簽名？
1. 打開簡訊或 LINE 傳來的連結
2. 核對地址、品項與金額
3. 在簽名欄用手指簽名
4. 按確認送出

簽名前請看清楚總額。送出後即代表你確認這張報價。

## 完工驗收要怎麼簽？
打開驗收或回報連結，查看施工照片。確認完成後簽名，必要時填滿意度。不要把連結轉給無關的人代簽。

## 簽名頁打不開怎麼辦？
用手機瀏覽器直接開完整連結。連結過期或已作廢時請廠商重寄。不要把畫面截圖再傳出去當正式簽名。

## 我簽完要去哪裡看？
同一條連結會變成已簽名狀態。之後要查進度，用廠商給的查詢頁或修繕登入，不要重簽一張新的。

## 金額不對可以拒簽嗎？
可以。不要簽名，直接回覆傳連結的人說明要改哪些品項。改完後會再收到新的連結。

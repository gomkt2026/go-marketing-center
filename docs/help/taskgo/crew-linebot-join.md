# 工班加入 LINE

## 我要怎麼加入公司的 LINE 機器人？
1. 向公司要 QR Code 或加入連結
2. 用 LINE 掃碼並按加入
3. 依畫面完成綁定或註冊
4. 綁定成功後即可看今日工作

沒有 QR Code 請直接問現場主管或後勤，不要搜來路不明的帳號。

## 註冊要準備什麼？
準備 LINE、公司給的統編或邀請資訊、個人照片、手機號碼。依畫面一步一步填，送出後等公司審核。

## 加入後沒有選單怎麼辦？
確認已加好友且沒有封鎖。對機器人傳一個字。仍沒有選單，請後勤確認你的 LINE 已綁到員工資料，且公司 LINE 服務有效。

## 我可以用自己的手機綁別人的工號嗎？
不可以。一支 LINE 對一位員工。綁錯請立刻告訴後勤解除後重綁。

## Web 後台帳號一定要有嗎？
不一定。多數工班只用 LINE 就夠。公司有幫你開後台帳號時，才用對方給的帳密登入網站。

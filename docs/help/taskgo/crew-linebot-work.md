# LINE 報工與完工

## 我要怎麼看今天的工作？
1. 打開公司的 LINE 機器人
2. 點「今日工作」
3. 看任務名稱、專案、地址、時間
4. 需要路線時點導航前往

沒有卡片代表今天沒被派工，或日期不是今天。請先問主管。

## 我要怎麼開始工作？
在任務卡片按「開始工作」，並允許分享位置。狀態會變成進行中。請在現場再按，不要在家先按。

## 施工照片要怎麼傳？
1. 點上傳照片或進入任務詳情
2. 選對應的任務
3. 拍照或從相簿選圖
4. 送出

系統可能加上時間與位置浮水印。單張請不要過大，網路不穩就換到訊號好的地方再傳。

## 我要怎麼回報完工？
在任務裡按完成任務或完工回報，必要時補照片與備註。送出後會變成待確認，等主管審核，不要重開一張新任務。

## 簽名要怎麼簽？
在任務詳情按任務簽名。工班簽自己的名字；需要上包或監工簽時選對應類型。用手指簽完按確認儲存。

## 上下班打卡在哪裡？
打開「我的資訊」。上班打卡與下班打卡都要分享位置。請開啟手機 GPS。忘記打卡不影響傳照片，但出勤紀錄會缺，請告訴主管。

## 為什麼看不到今日工作？
確認任務日期是今天、你是被指派的人、LINE 已綁定。剛被派工可先關掉對話再重開，或傳「今日工作」。

## 一週的工作要怎麼看？
在機器人選一週工作或行事曆。用來排交通與備料。當日執行仍以今日工作為準。

# 工班手機版

## 手機網頁要怎麼進？
用手機瀏覽器打開公司給的 TaskGo 網址並登入，會進入手機版。可看自己的任務、專案與通知。沒有後台帳號時，請繼續用 LINE。

## 手機版任務跟 LINE 是同一筆嗎？
是。主管派的同一張任務，LINE 與手機版都會看到。完工或傳照片後兩邊都會更新，不要重複建單。

## 手機版要怎麼傳照片？
打開任務詳情，用相機或相簿上傳並送出。請確認選到正確任務。

## 怎麼加到手機桌面？
iPhone 用 Safari 打開後按分享，選加入主畫面。Android 用 Chrome 打開後按選單，選安裝應用程式。

## 離線還能用嗎？
已載入的任務列表可能還看得到。傳照片、開工與完工需要網路。連線恢復後再送一次即可。

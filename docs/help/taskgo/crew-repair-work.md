# 場勘與施工回報

## 場勘照片要怎麼上傳？
1. 打開主管傳來的場勘或派工連結
2. 確認地址，需要時按導航
3. 上傳現場照片
4. 填工班姓名與電話
5. 按送出

場勘送出後該步驟即完成，不必等客戶驗收。

## 施工回報要拍哪些照片？
施工前、施工中、施工後都要拍，缺一段不能送出。施工中請拍到現場正在做的畫面。系統可能檢查是否有人在施作；失敗時可依畫面勾例外並填理由。

## 一張派工單有很多品項怎麼回報？
打開主管給的那一個派工單連結，會看到場勘與各品項清單。逐項按「前往回報」，不必跟主管要很多組網址。

## 漏水場勘要填什麼？
若頁面出現漏水欄位，請填漏水位置與何時會漏等必填項，再上傳照片後送出。不清楚的欄位先問現場負責人，不要空白亂填。

## 照片傳錯了怎麼辦？
請後勤在案件裡重開該筆回報，再開同一個連結重傳。不要另外找陌生連結上傳。

## 完工後客戶要怎麼驗收？
把同一個回報或驗收連結傳給客戶，請對方簽名與評分。你自己不要代簽。

# 成本與財務

## 我要怎麼看專案成本？
1. 左側打開「成本管理」或「成本總覽」
2. 選專案
3. 查看預算與實際支出
4. 需要明細再點進該筆成本

沒有進階模組權限時，這個選單不會出現。

## 財務總覽在看什麼？
左側「財務總覽」看組織收款與支出摘要。「收款報表」追應收。「請款流程」管對客戶請款。「工班請款」管工班請款。

## 我要怎麼建立請款？
1. 打開「請款流程」
2. 選專案或來源單據
3. 確認金額與期間
4. 按送出請款
5. 依公司流程補發票或收款紀錄

## 工班請款要怎麼審？
打開「工班請款」，點進該筆核對工項與金額，通過或退回。通過後才進入後續付款作業。

## 成本跟請款對不上怎麼查？
先確認專案、日期區間與含稅設定一致。再比對成本明細與請款調整（扣款、追加、退款）。修繕案件也可從案件卡片看收付款狀態。

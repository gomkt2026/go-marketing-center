# 客戶與估價單

## 我要怎麼新增客戶？
1. 左側打開「客戶管理」
2. 按新增
3. 填客戶名稱與聯絡方式
4. 按儲存

之後建專案或估價單可直接選這位客戶。

## 我要怎麼開估價單？
1. 左側打開「估價單」或「報價工作台」
2. 選客戶與專案（可選）
3. 加入品項、數量、單價
4. 確認小計與稅額
5. 按儲存

需要標準品項時，先到品項庫建好再套用。

## 估價單開好要去哪裡看？
回到「估價單」列表，用客戶或日期搜尋。點進可下載、複製給客戶或繼續改。

## 怎麼把估價轉成後續作業？
依公司流程，可從已確認的估價進入專案、合約或請款。修繕案件則在修繕管理的報價工作檯另外處理客戶報價單。

## 品項常常重複輸入怎麼辦？
到品項庫或共用目錄先建標準品項。開估價時直接挑選，比較不會算錯單價。

# 每日報表與出勤

## 我要怎麼看出勤？
1. 左側打開「出勤報表」
2. 選日期範圍、專案或員工
3. 查看上下班打卡時間與位置
4. 需要列印或交給會計時按匯出

## 每日報表在哪裡看？
左側打開「每日報表」。可看各專案或員工當天完成數、打卡與上傳檔案數。適合晨會或日結。

## 工班沒打卡會怎樣？
任務與照片仍可回報。出勤列會缺該時段。請對方開啟手機定位後補打，或請負責人依公司規定人工註記。

## 打卡位置不對怎麼查？
打開該筆打卡看地圖座標。請工班確認 GPS 已開，並在戶外或訊號較好處重打。後勤不要在後台改定位紀錄來「對齊」現場。

## 報表匯出中文亂碼怎麼辦？
先改用 Excel 再開。若 PDF 仍亂碼，改瀏覽器後再匯一次，或洽客服。

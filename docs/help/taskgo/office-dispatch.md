# 派工行事曆

## 我要怎麼新增一筆派工？
1. 左側打開「派工行事曆」
2. 點日期或按「新增任務」
3. 填任務名稱、工種、執行日期、指派人員
4. 按儲存

也可先到專案詳情新增任務，再回來行事曆調整日期。

## 送出後要去哪裡看？
同一天的行事曆卡片，或左側「派工紀錄」。工班綁定 LINE 後會收到通知。

## 月、週、日視圖要怎麼切？
行事曆上方可切換月／週／日。右側面板會列出當日或選取日的任務。

## 顏色代表什麼？
待派工、已派工、進行中、待確認、已完成、需改善會用不同顏色。把滑鼠移到卡片也可看狀態文字。

## 我要怎麼改派給別人？
點開該筆任務，改指派人員後儲存。原工班與新工班都會依通知設定更新。

## 可以一次指派多筆嗎？
在派工行事曆選好日期，勾選要指派的任務，按批次指派，選人員後確認。

## 工班說看不到今日工作？
先確認任務日期是今天、人員指派正確，且對方已加入並綁定 LINE。組織的 LINE Bot 訂閱也要在有效期內。

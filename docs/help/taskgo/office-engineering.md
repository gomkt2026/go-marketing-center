# 工程設置

## 我要怎麼新增工種？
1. 左側打開「工程設置」
2. 進入工種管理
3. 按新增，填工種名稱
4. 可再歸到工種類別
5. 按儲存

建專案與派工時就能選到這個工種。

## 專案類型跟任務類型差在哪？
專案類型用來分類案子，例如住宅裝修或修繕。任務類型用來分類單筆工作。兩者都在工程設置維護。

## 設備與耗材主檔要在哪裡建？
在工程設置打開「設備與耗材」。先新增設備機型，再新增該機的巡檢或換耗材項目，並填週期月數。之後才能在專案掛維護合約。

## 主檔改名會影響舊專案嗎？
主檔改名不會改已經套進專案的項目。各專案可自己改週期與到期日，不會回寫主檔。

## 為什麼派工時選不到工種？
該工種可能未建立或已停用。回工程設置檢查名稱與啟用狀態，再重新整理派工畫面。

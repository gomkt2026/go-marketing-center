# 改善任務

## 什麼時候要開改善任務？
審核時認為現場沒達標、要重做或補做，就把原任務標成需改善，再發起改善任務，讓同一條追蹤鏈接得起來。

## 我要怎麼發起改善任務？
1. 左側打開「改善任務」，或從原任務按發起改善
2. 填改善原因
3. 指派人員與新日期
4. 按儲存

工班會收到新的待辦，不會跟已完成的舊任務混在一起。

## 發起後要去哪裡追蹤？
在「改善任務」列表看狀態，或從原任務點進追蹤鏈。完成後一樣走審核。

## 改善任務跟一般派工差在哪？
改善任務會記住上一筆任務，方便看出是哪一次沒過。派工、打卡、上傳照片的操作與一般任務相同。

## 可以改指派或改日期嗎？
可以。打開該筆改善任務編輯人員與日期後儲存。請同步通知工班，避免跑錯現場。

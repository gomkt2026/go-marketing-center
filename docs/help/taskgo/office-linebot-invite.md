# 邀請工班加入 LINE

## 我要怎麼邀請工班加入？
1. 左側打開「LINE Bot 邀請」
2. 顯示組織的加入方式或 QR Code
3. 把圖片或連結傳給工班
4. 請對方加入好友並完成綁定

綁定後才能收今日工作與完工通知。

## 工班加入後我要做什麼？
到人員管理確認該員工已對上 LINE。若名單裡還沒有這個人，先新增員工與角色，再請對方用正確手機完成綁定。

## 工班說 Bot 沒反應？
確認對方沒封鎖官方帳號、已綁定，且組織 LINE 訂閱有效。請對方對 Bot 傳一個字測試。仍無回應再查該員工的 LINE 綁定狀態。

## 可以給還沒建檔的人掃碼嗎？
可以先加入好友。之後仍要在人員管理建檔或走工班自助註冊，後勤才能派工給他。

## QR Code 可以貼在工地嗎？
可以。請用目前後台顯示的那一組，過期或換過 Bot 的舊圖會連錯。

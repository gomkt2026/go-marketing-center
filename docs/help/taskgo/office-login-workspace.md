# 登入與工作台

## 我要怎麼登入後台？
1. 打開 TaskGo 網址
2. 輸入帳號與密碼
3. 按登入
4. 進入工作台或儀表板

帳號通常是手機號碼。登入後才看得到右側小幫手與右上角真人客服。

## 忘記密碼怎麼辦？
1. 在登入頁按「忘記密碼」
2. 輸入註冊時的 Email
3. 到信箱點重設連結
4. 設定新密碼後再登入

重設連結有時效，請儘快完成。

## 為什麼登不進去？
先確認帳號與密碼沒打錯。帳號被停用請找組織負責人恢復。瀏覽器快取異常時，清快取或換 Chrome 再試。

## 登入後要去哪裡開始？
左側打開「工作台」看常用入口，或打開「儀表板」看今日待辦與待審核。第一次使用請先完成組織資料、工種與第一位員工。

## 工作台跟儀表板差在哪？
工作台是依你的角色列出可進的功能區。儀表板是看今日任務、待確認與專案摘要。OWNER 另外有駕駛艙可看全組織概況。

## 我可以切換角色或入口嗎？
若帳號有多個入口（例如專案／任務／報價），畫面上方或側欄可切換工作區。切過去之後，左側選單會跟著變。

## 一個帳號能同時管兩間公司嗎？
目前一個登入帳號對應一個組織。要管另一間公司，請用該組織發給你的帳號另外登入。

# 維護合約

## 維護合約是做什麼的？
用來管「這個客戶據點每隔幾個月要巡檢或換耗材」。系統不會一次生出大量任務，而是先列出到期項目，你再點派工，避免行事曆被塞滿。

紫色的合約是收款／報價合約。青色的維護才是巡檢與換耗材。兩者分開。

## 第一次要先做什麼？
1. 到工程設置建立設備機型
2. 為該機型加上巡檢或換耗材項目，並填週期月數
3. 到客戶專案按青色「維護」掛上合約期間
4. 從主檔套用機型或單項

下次到期日等於起始日加上週期月數。

## 我要怎麼看這個月該做的維護？
左側打開「當月維護」，右上角選年、月。表格會列出到期日、專案、項目、類型與狀態。

## 到期項目要怎麼派工？
在當月維護或該列按「派工」，選工班後送出。之後走既有任務流程：LINE 通知、打卡、完工。任務完工後，系統會把下次到期日加上週期月數。

## 沒有主檔可以手建嗎？
可以。在專案維護頁按手建項目，填名稱、類型、週期與下次到期日。之後若補了主檔，新專案再改用套用即可。

## 刪除項目會刪主檔嗎？
專案裡刪除只拿掉這個據點的週期項目，主檔還在。主檔已被套用過時，刪除會改成停用，避免舊合約斷掉。

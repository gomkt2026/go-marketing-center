# 後勤手機版

## 後勤用手機要開哪一頁？
在手機瀏覽器打開 TaskGo，登入後進入 `/mobile`。可看專案、任務、派工、日報與修繕。畫面是給現場與外出使用，功能比電腦後台精簡。

## 手機版要怎麼審核任務？
打開手機版任務或派工，找到待確認，點進看照片後通過或退回。複雜篩選與匯出請回電腦後台。

## 修繕案件手機怎麼看？
手機版打開修繕列表，點進案件看出度與待辦。複製場勘或派工連結給工班的操作與電腦相同。

## 怎麼把手機版加到主畫面？
iPhone 用 Safari 打開後，按分享再選加入主畫面。Android 用 Chrome 打開後，按選單再選安裝應用程式。

## 手機版跟 LINE Bot 要一起用嗎？
後勤審核與改派用工班手機版或電腦。工班收任務、打卡、傳照片以 LINE 為主。兩套資料是同一筆，不要重複建單。

# 組織與人員

## 我要怎麼改公司名稱或資料？
1. 左側打開「組織設定」
2. 編輯公司名稱、地址、統編
3. 可上傳 Logo
4. 按儲存

只有組織負責人能改這些欄位。

## 我要怎麼新增員工？
1. 左側打開「人員管理」
2. 按「新增員工」
3. 填姓名、手機，Email 可選填
4. 選角色（例如專案經理或工班）
5. 按儲存

需要對方自己登入後台時，再在該員工資料裡建立登入帳號。

## 員工角色要怎麼選？
專案經理可管被指派的專案、派工與審核。工務經理偏現場複驗。工班只接收任務與回報。人資看出勤與薪資。倉管看倉庫與發料。負責人擁有全部權限。

## 怎麼幫員工建立後台登入帳號？
1. 打開該筆員工
2. 找到登入帳號區塊
3. 設定帳號與密碼
4. 按建立登入帳號
5. 把帳密交給對方

沒有登入帳號的工班，仍可用 LINE 收任務。

## 員工離職要怎麼處理？
到人員管理打開該員工，停用或移除登入權限，並確認 LINE 不再接收新派工。歷史任務與照片會留在專案裡。

## 工種要在哪裡先設好？
到「工程設置」新增公司常用工種與專案類型。之後建專案與派工才能選到正確工種。

# 薪資與請假

## 我要怎麼看薪資？
1. 左側打開「薪資中心」
2. 選計薪期間
3. 核對出勤、任務與扣款
4. 依公司流程確認後再發放

只有負責人或人資看得到完整薪資。

## 扣款項目要在哪裡設？
打開「扣款項目字典」先建名稱與計算方式。計薪時就能套用，不必每次手打。

## 員工請假我要怎麼審？
1. 左側打開「請假審核」
2. 點進申請看假別與期間
3. 通過或退回
4. 通過後出勤與排班會依設定更新

工班也可從 LINE 請假頁送出，後勤仍在這裡審。

## 請假跟派工衝突怎麼辦？
先確認該日是否已有派工。通過請假前，請把衝突任務改期或改派，避免工班同時收到出勤與請假通過。

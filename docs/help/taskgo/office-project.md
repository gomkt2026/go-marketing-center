# 專案管理

## 我要怎麼建立新專案？
1. 左側打開「專案管理」
2. 按「新增專案」
3. 填專案名稱、施工地址、起迄日期
4. 選專案類型與專案經理
5. 按建立

客戶與預算可之後再補。

## 建立後要去哪裡看？
回到「專案管理」列表，用名稱或狀態搜尋。點進專案可看任務、成員、進度與成本。

## 專案狀態有哪些？
常見是規劃中、進行中、暫停、已完成、已取消。列表可用狀態篩選。完工且不需再派工的案子，可依公司流程封存。

## 怎麼指派專案經理？
建立專案時在「專案經理」欄位選擇人員。之後也可在專案詳情的設定裡改。一位專案可指派多位經理。

## 怎麼在專案裡加人？
打開專案詳情，到成員或人員區塊新增員工。工班被派工後也會出現在該專案相關任務裡。

## 專案地址錯了怎麼改？
打開專案詳情，編輯基本資料後儲存。地圖與導航會跟新地址走。

## 專案地圖怎麼用？
左側打開「專案地圖」，圖上會標出有地址的專案。點標記可看概要並進詳情。

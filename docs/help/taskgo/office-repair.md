# 修繕管理

## 修繕案件從哪裡進來？
兩種方式。一是把接單設定裡的公開報修連結給委託方自己填。二是客戶打電話進來時，在「報修單據」按「手動新增」。兩種建立後的後續流程相同。

## 我要怎麼手動新增案件？
1. 左側打開「修繕管理」
2. 在報修單據按「手動新增」
3. 填聯絡人、電話、地址、修繕內容
4. 補單時務必填實際受理日
5. 按建立案件，記下系統給的案號

## 接單設定要先做什麼？
只有負責人能改。到修繕管理的接單設定：產生公開報修連結、設標準範本、案號前綴、參考圖。沒設範本時案件仍會建立，但不會自動產生後續任務。

## 場勘連結要怎麼給工班？
打開案件卡片，複製場勘連結或廠商派工單連結傳給工班。工班用手機打開就能上傳現場照片。場勘回報完成即算該步驟完成，不必等業主驗收。

## 報價跟派工單要怎麼開？
打開案件的報價／派工工作檯。新增給業主看的客戶報價單，以及給廠商的派工單。也可以匯入廠商報價後再加成。兩張都好了再按傳送，產生簽名連結。

## 一案要拆給兩家工班怎麼做？
在客戶報價單裡每個品項指定供應商，再按「儲存並產生廠商派工單」。系統會依供應商拆成多張派工單。之後改品項可再按同一顆按鈕，同一供應商會沿用原單。

## 連結複製出去會帶什麼？
複製客戶報價或廠商派工連結時，會帶一段可直接貼上的訊息與短網址。工班只要一組派工單連結，打開後可逐項去場勘或施工回報。

## 工班照片傳錯要怎麼重開？
到案件詳情對該回報按重開修改，工班即可重新上傳。特殊現場若不需要辨識施工人員，可在該張派工單關閉人員辨識。

## 財務下一步在哪？
客戶報價簽名後可建合約進請款。廠商派工簽名後可轉付款單。案件卡片下方會顯示目前收付款狀態。

# 訂閱與付款

## 我要怎麼看目前方案？
1. 以負責人登入
2. 左側打開「付款與訂閱」或訂閱狀態
3. 查看平台方案與員工 LINE 席次是否在有效期

只有負責人或管理者能改訂閱。

## 我要怎麼續約或升級？
到付款與訂閱選方案，依畫面完成付款。升級通常立即生效。降級會等到下一個計費週期。

## 到期後還能用嗎？
資料會保留一段時間，仍可登入查看。建立新專案、新任務、LINE 與匯出可能暫停，請在到期前續約。

## 員工 LINE 為什麼不能用了？
到訂閱與 LINE 使用統計確認席次與到期日。過期後工班 Bot 會停用，續約後再請對方重傳一次訊息測試。

## 付款失敗怎麼辦？
確認付款頁沒有關掉、網路穩定後重試。已扣款但畫面沒更新時，先刷新訂閱狀態；仍沒開通請留資給客服並提供付款時間。

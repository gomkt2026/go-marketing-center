# 派工紀錄與審核

## 我要怎麼看全部派工紀錄？
1. 左側打開「派工紀錄」
2. 用日期、專案、人員或狀態篩選
3. 點一筆看照片、簽名與備註

這裡是審核與補件的主要入口。

## 任務狀態是怎麼走的？
尚未指派是待派工。指派後是已派工。工班開始後是進行中。工班按完工後是待確認。你按通過變成已完成；退回則是需改善。

## 工班回報後我要怎麼審核？
1. 儀表板或派工紀錄找「待確認」
2. 打開任務看照片、文件、簽名
3. 沒問題按已完成
4. 要重做按需改善，並說明原因

## 審核後工班看得到嗎？
通過後任務變已完成，工班可在 LINE 或手機版看到結果。退回後工班需依說明補做再開工或再送審。

## 照片或簽名看不到怎麼辦？
打開該筆任務的檔案區，確認工班有上傳。若上傳失敗請對方檢查網路與檔案大小後重傳。仍沒有檔就請對方用 LINE 再傳一次並指定同一任務。

## 我可以自己幫工班標記完工嗎？
有派工權限的後勤可在任務詳情依現況更新狀態。正式流程仍建議等工班上傳照片再審，方便之後對帳與客訴查證。

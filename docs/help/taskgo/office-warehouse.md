# 倉儲與叫料

## 工班叫料我要去哪裡審？
1. 左側打開「工班叫料」
2. 找到待審核申請
3. 核對專案、品項與數量
4. 核准或駁回

工班也可從 LINE 裡的材料申請送出，後勤都在這裡看。

## 我要怎麼發料？
1. 先確認倉庫與庫存有該品項
2. 打開「發料管理」
3. 選專案與品項數量
4. 按發料
5. 需要現場點收時，把材料檢查連結給工班

## 回廠要怎麼入帳？
打開「回廠管理」建立回廠單，選回倉庫與品項。工班可用回廠檢查頁拍照確認後，後勤再核對入庫。

## 倉庫跟庫存差在哪？
倉庫是地點主檔。庫存是各倉庫現有數量與進出紀錄。先建倉庫，再做進貨、發料、回廠。

## 叫料核准了但現場說沒收到？
到發料管理確認是否已出庫，並核對送達專案。再請工班用材料檢查頁回報實收數量與照片。

# 第一次使用

## 第一次要怎麼開始用？

1. 加入門市的 LINE 官方帳號。
2. 在聊天室打開下方選單。
3. 還沒填過會員資料時，先完成「會員登錄」。
4. 填好後回到聊天室，點選單的「會員預約洗滌」就可以送洗。

請在 LINE App 內開啟，不要用一般瀏覽器另開網頁。

## 選單上各按鈕是做什麼的？

- 會員預約洗滌：建立到府或貨運送洗單。
- 會員點數查詢：看點數餘額，並在「送洗訂單」分頁找訂單。
- 會員好康：知識問答、電子衣櫥等加值功能。
- 洗滌價目查詢：看參考價目。
- 洗滌專業知識：洗護文章與個人分析紀錄。

門市自助送洗不在這個選單裡，請掃門市現場 QR Code。

## 為什麼在 LINE 外打不開？

這些頁面必須從官方帳號選單或 LINE 通知卡片進入。若出現無法登入，請關閉後再從選單重開一次。

## 還有問題找不到答案怎麼辦？

在右下角小幫手說明仍不夠時，可留下姓名與電話，門市會再聯繫你。也可以撥打門市客服電話。

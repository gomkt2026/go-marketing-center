# 到府送洗預約

## 我要怎麼預約到府送洗？

1. 先完成會員登錄。
2. 從選單打開「會員預約洗滌」。
3. 確認姓名、電話、地址。
4. 選擇洗好後要「門市自取」或「司機送回」。
5. 選擇服務區域，確認該區最低送洗金額。
6. 用三批選品勾選衣物／鞋包／寢具，或展開詳細目錄。
7. 若衣物已放管理室，可上傳放置照片並勾選確認。
8. 勾選注意事項與洗滌風險說明。
9. 按底部「確認送洗」。

送出後請留意 LINE 通知。門市受理後會安排司機到管理室或指定地點取件。

## 還沒註冊可以下單嗎？

不行。頁面會提示「尚未完成會員登錄」，請先去填會員資料，再回到「會員預約洗滌」。

## 最低送洗金額怎麼算？

依你選的服務區域顯示該區低消（常見為 600 或 1200 元分級）。實際金額以頁面上顯示為準。未達低消可能無法用到府收送，可改門市送洗或詢問門市。

## 「三批選品」要怎麼選？

可選：

- 送洗衣物一批
- 送洗鞋包一批
- 送洗寢具一批

需要更細項目時，展開詳細目錄再加減數量。這是預約內容，正式報價以門市清點後為準。

## 管理室照片、注意事項沒勾為什麼送不出去？

頁面會要求勾選「衣物已放置管理室／警衛室」以及洗滌注意事項。有必填檢查沒過時，請往回補照片或勾選後再送出。

## 洗好後要選門市自取還是司機送回？

- 門市自取：洗好後到門市取，現場由服務人員協助簽名。
- 司機送回：洗好後司機送到你的地址，運費依門市規則計算。

下單後若要改，請聯絡門市，不要自己重開一張單。

## 外縣市貨運寄送怎麼用？

選擇貨運寄送後，請自行把衣物寄到門市指定地址。洗完後門市再用貨運寄回。托運單號請依頁面或門市指示補上。這與司機到府取件不同。

## 為什麼首次到府要先預收？

部分品牌第一次到府收送，會依地址預收低消與運費。請在預收頁用 LINE Pay 或銀行轉帳完成。

- 門市覆核報價後，預收金額會從總價扣除。
- 若正式報價比較低，差額退回你的點數帳戶。

預收失敗可再試一次，或改用轉帳並依指示上傳證明。預收成功後等 LINE 通知後續進度即可。

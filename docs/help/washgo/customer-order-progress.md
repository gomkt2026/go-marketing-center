# 訂單進度

## 我要怎麼查看訂單進度？

1. 打開 LINE 通知的「查看訂單詳情」，或
2. 打開選單「會員點數查詢」→「送洗訂單」分頁，點進該筆。

頁面標題是「訂單即時進度」，會顯示時間軸、品項狀態與報價明細。

## 「已報價」和「洗滌中」差在哪裡？

- 已報價：門市已送出金額，請先完成確認與簽名，否則不會開始洗。
- 洗滌中：已確認，衣物在清洗或品管流程中。
- 可取件：洗好了。門市自取請到店；司機送回請等配送通知。
- 報價爭議：你拒絕過報價，等門市重報或聯絡。

找不到訂單時，請從 LINE 通知或「送洗訂單」重新進入，不要用瀏覽器收藏舊網址。

## 每一件衣服的進度在哪裡看？

訂單進度頁可以看到品項列表。若只要看各件狀態，可開「逐件進度」。品檢未通過或重洗時，頁面會標示，完成日可能往後延。

## 洗好了要去門市取還是等司機？

看下單時選的方式：

- 門市自取：出現「可以取件了」時，請到門市由服務人員協助確認與簽名。自取說明頁沒有簽名鈕，簽名在櫃檯完成。
- 司機送回：等配送通知；送達時依司機指示簽收。訂單頁也可看司機送回照片。

## 預計完成日期準嗎？

那是依門市工時估算。遇重洗、修補或尖峰期可能延後，請以最新狀態與 LINE 通知為準。

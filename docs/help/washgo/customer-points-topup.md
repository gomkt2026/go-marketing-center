# 點數與儲值

## 我要怎麼查點數和訂單？

1. 從選單打開「會員點數查詢」。
2. 上方是目前可用點數。
3. 「送洗訂單」看進行中與歷史訂單。
4. 「點數紀錄」看加點、扣點明細。

還沒登錄會提示先完成會員資料。1 點 = NT$1，確認報價時折抵洗滌費用。

## 我要怎麼儲值？

1. 在點數頁按「儲值加點」，或從報價頁的「前往儲值」進入。
2. 選擇受理門市。
3. 選方案檔位或輸入自訂金額。
4. 用 LINE Pay（成功後即時入點）或銀行轉帳（上傳截圖，門市確認後入點）。

付款成功後發票由門市開立，不是當場電子發票。

## 為什麼一定要選受理門市？

儲值與發票由該門市處理。選錯門市可能入點變慢或發票開錯，請選你常去或這次送洗的那一家。

## 店長掃碼加點怎麼用？

在點數頁打開「顯示店長掃碼加點」，把 QR Code 給櫃檯掃描。適合現場現金加點、或送洗時點數不夠請櫃檯代儲。

## 儲值成功但點數沒增加怎麼辦？

- LINE Pay：先下拉重整點數頁；仍沒有請把付款時間告訴門市。
- 轉帳：需等門市核對截圖後才入點，不是按下傳就立刻到帳。

儲值是為了確認報價。入點後請回到「報價確認」頁再簽一次，不要重開新訂單。

## 洗完的衣服「歸檔到衣櫥」是什麼？

完成的訂單可以把衣物存進電子衣櫥，方便之後看洗護紀錄或穿搭。這不是必做步驟，不影響取件。

# 報價確認與簽名

## 收到「報價已送出」之後要怎麼確認？

1. 打開 LINE 通知卡片，或到「會員點數查詢 → 送洗訂單」點進該筆訂單。
2. 進入「報價確認與簽名」。
3. 核對品項與金額。
4. 若有洗滌風險說明，請閱讀並勾選。
5. 確認點數扣抵預覽（1 點 = NT$1）。
6. 完成電子簽名後送出。

簽完後訂單進入洗滌流程。點數為預付折抵；訂單完成後另依門市規則累積回饋。

## 確認時會扣多少點？點數不夠怎麼辦？

頁面會顯示這次要扣的點數。不夠時會出現「前往儲值」。

1. 完成儲值（LINE Pay 即時入點，或轉帳待門市入帳）。
2. 回到這一頁重新確認。
3. 人不在現場時，也可以請櫃檯代為確認。

## 有預收的話，畫面上的金額怎麼看？

會看到覆核報價總額、已預收、以及還要付的餘額。已預收會從總價扣除；預收比報價多的部分會退回點數。

## 可以拒絕報價嗎？

可以，按「拒絕此報價」。門市會收到通知，可能再報一次或協助退件。訂單會進入爭議處理，請等門市聯絡，不必重開新單。

## 為什麼要簽洗滌風險免責？

部分材質洗滌有縮水、掉色等風險。門市清點後可能另傳「洗滌風險確認」頁，只需閱讀並勾選，不一定再簽一次名。不確認可能影響後續洗滌，有疑問請先問門市。

## 為什麼又要再簽一次（追加報價）？

洗滌過程若新增項目，門市會再送一次「追加洗滌報價確認」。簽名代表同意這筆追加費用，點數會再扣一次對應金額。

## 簽完名多久開始洗？

門市排程後開始。進度請到「訂單即時進度」查看，或等 LINE 狀態通知。

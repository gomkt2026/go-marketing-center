# 會員登錄

## 我要怎麼成為會員？

1. 從 LINE 官方帳號打開「加入會員」或「會員登錄」。
2. 確認姓名（可沿用 LINE 顯示名稱）。
3. 填寫手機號碼（必填）。
4. 到府取件請順便填地址，之後下單比較快。
5. 送出後即完成登錄。

成功畫面會提示：請回到 LINE 聊天室，點選「會員預約洗滌」建立送洗單。

## 姓名、手機、地址哪些一定要填？

- 姓名、手機：必填。
- 地址：到府收送建議填；只做門市自助送洗可先不填。

## 已經是會員，要怎麼改電話或地址？

1. 再開一次會員資料頁。
2. 已登錄會顯示資料卡，進入修改。
3. 改完送出即可。之後新訂單會用新資料。

## 還沒儲值可以先送洗嗎？

可以。儲值用來折抵洗滌費用（1 點 = NT$1），不是加入會員的條件。首次到府收送有些品牌會先請你預收低消與運費，與「先儲值才能下單」不是同一件事。

# 沒有任務時

## 為什麼今日任務是空的、也沒有推播？

任務要店長先排才會出現。請確認：

1. LINE 綁的是司機（或兼任司機）身分，且人員是啟用中。
2. 店長是否已在「運費排程」勾選今天的站，或在「派遣／回貨派遣」指派你。
3. 是否選錯品牌、或手機時間不是今天。

沒有 LINE 時改用後台登入看司機任務。不要自己在系統裡建任務。

## 客戶不在家或地址找不到怎麼辦？

用任務卡片的電話或請店長聯絡客人。不要把未完成的站點標完成。改約後等店長更新排程，再重新打開今日任務。

## 地圖導航怎麼開？

任務卡片有 Google 地圖連結，點了會用手機地圖 App 導航。送達後記得回到 LINE 把照片補齊並按完成。

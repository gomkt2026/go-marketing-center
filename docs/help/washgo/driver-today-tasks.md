# 今日任務

## 今天的任務在哪裡看？

用 LINE 員工／司機選單打開「今日任務」。沒有 LINE 時，用後台帳號登入，只能進「司機任務」與送回詳情。

頁面上方是「今天走這條路」時間軸，依店長排程的順序走。點時間軸或卡片，可在同一頁完成取件或送回，不必再找舊的獨立頁。

## 「今天走這條路」是什麼意思？

那是今天的站點順序，例如：到府取件、回門市拿洗好的衣服、再去客戶家送達、或臨時／工廠站。請照順序走，不要跳站，路線與時間才準。

## 舊的取件、送回連結還能用嗎？

較新的取件連結會帶回今日任務。舊頁可能還在，但請以今日任務為準，避免同一單做兩次。

運費方案簽名目前不用做。店長排程後任務會直接出現。

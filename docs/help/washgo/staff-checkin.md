# 收貨覆核

## 收貨覆核要做什麼？用電腦還是手機？

目標：拆袋、對品項、定價、拍照、確認洗滌風險、完成簽名、需要時印單。

- 櫃檯電腦：後台「收貨覆核」。
- 現場手機：LINE 員工選單「收貨覆核」，再點進該筆。

舊的「櫃檯」連結會轉到收貨覆核，功能相同。

## 哪些訂單會出現在待覆核？

- 司機已取回、狀態為已取件或已到店
- 客人門市自送、待覆核
- 自助送洗已建單、待櫃檯覆核

從列表點進單筆後逐件登錄或核對。店長可用「快速改價」調整目錄價，但不取代這一筆的覆核。

## 自助單為什麼不能覆核？

客人必須先在自助頁完成簽名。未簽名時收件匣會提示，請客人補簽後再覆核。

## 拍照估價可以當成正式價格嗎？

不行。拍照估價與價格估算頁只是參考。正式金額以覆核時登錄的品項與單價為準，之後還要再建立報價給客人確認。

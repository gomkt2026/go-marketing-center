# 客戶與點數

## 要怎麼幫客人儲值？

1. 打開後台「點數儲值」。
2. 用電話、姓名或掃描客人點數頁的 QR 找到會員。
3. 選現金、轉帳或 LINE Pay，輸入金額。
4. 送出後點數入帳。發票之後在「儲值發票」處理。

查無會員可在同一頁快速建檔。人工補點請在備註寫原因，方便對帳。

## 要怎麼查客人資料、點數和訂單？

打開「客戶」：

- 搜尋電話或姓名
- 看點數餘額、訂單、內部備註
- 確認是否已綁定 LINE

批次匯入用「客戶匯入」。刪除客人需有權限，一般櫃檯請改用備註，不要刪除。

## 客人說點數不對怎麼查？

1. 在客戶或儲值報表核對加點與扣點時間。
2. 確認報價是否已確認（確認當下才扣點）。
3. 轉帳儲值是否已入帳。
4. 仍對不上就在訂單備註記時間，交給店長查儲值報表。

# 員工加入與帳號

## 新進人員要怎麼加入品牌？

1. 店長或品牌負責人在後台「人員」發出邀請（QR 或連結）。
2. 用手機 LINE 掃描或打開邀請。
3. 在「員工加入」頁確認品牌與角色。
4. 送出後即綁定 LINE，之後用員工選單進系統。

必須用手機 LINE App，電腦瀏覽器無法完成綁定。

## 櫃檯、品管、店長有什麼差別？

- 櫃檯：收件、清點、報價、儲值、待取件。
- 品管：洗後檢查、通過／重洗、包裝分流。
- 店長：上述都能做，另可看營運待辦、派遣、設定。
- 司機：看「今日任務」，不走櫃檯選單。

同一人若被加上兼任角色，LINE 選單會出現對應入口。

## LINE 換機或打不開員工頁怎麼辦？

打開「重新綁定 LINE」頁，依畫面用新的 LINE 帳號完成綁定。綁定前請先請店長確認人員狀態是啟用中。

電腦請改登 https://washgo.pages.dev 後台。LIFF 員工頁是給手機現場用的。

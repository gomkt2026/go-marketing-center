# 開班與待辦

## 開班先看哪一頁？

登入後台後打開「營運中心」（待辦）。上面是指標卡，下面是依狀態排列的佇列。側欄紅字數量代表該模組待處理筆數，建議依序處理：收件 → 派遣 → 清點 → 報價 → 品管 → 待取件。

手機可用底部快捷列的「待辦」回到這一頁。

## 只想看某一個狀態怎麼做？

用狀態篩選，例如只看草稿、已到店、清點完成、報價爭議。櫃檯工作台也可以依階段切換，專心做當下那一段。

## 後台待辦和 LINE 員工收件匣有什麼不同？

- 後台營運中心：店長或櫃檯在電腦上看全貌、點進各模組。
- LINE「待接單」：手機快速受理客人從 LINE 送來的草稿單。

兩邊看到的是同一批訂單，選你當下方便的裝置即可。

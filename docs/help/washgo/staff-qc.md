# 品管

## 品管要在哪裡做？

- 電腦：後台「品管」，適合批次通過與包裝分流。
- 現場：LINE「品管」掃碼連續檢查，或打開單筆／單件頁。

待品管包含洗滌完成待檢、以及重洗後再檢的訂單。

## 不合格或要重洗怎麼操作？

1. 打開該件品管頁。
2. 選未通過，並填污點或原因。
3. 依畫面送出重洗。達到重洗上限時依提示交給店長，不要自行略過。

通過的件可繼續包裝。電腦品管頁在整單完成後會問配送分流。

## 洗好要通知自取還是派司機？

在品管包裝完成後的分流選擇：

- 門市自取：之後到「待取件管理」通知客人來取。
- 司機送回：進入待派遣，指派回送司機。
- 貨運寄回：依貨運出貨流程。
- 回門市：衣物先回原收件門市再處理。

分流選錯會讓客人跑錯地方，送出前請對一下訂單的取件方式。

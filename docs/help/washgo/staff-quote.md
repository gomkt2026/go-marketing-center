# 報價

## 清點完要怎麼送報價？

1. 電腦打開「報價」列表，或手機待辦的報價分頁。
2. 點進清點完成的訂單。
3. 核對品項金額與點數扣抵。
4. 送出報價。客人會收到 LINE 通知去簽名確認。

送出後狀態為已報價，等客人確認才進入洗滌。

## 客人不會用 LINE 確認怎麼辦？

在報價頁使用「代客確認」。請當面核對金額並取得同意後再代按。門市自助、部分 Kiosk 情境可能略過這一步，依畫面提示為準。

免扣點會員送出報價時不會扣點，但仍要完成確認流程。

## 客人拒絕報價（爭議）要怎麼處理？

到報價列表或營運中心的「報價爭議」：

1. 查看客人拒絕的那一筆。
2. 調整金額或品項後再次送出。
3. 客人會再收到確認通知。

不要另外開一張新單，以免點數與衣物對不上。

## 報價和追加報價差在哪？

第一次是整單報價。洗滌中若新增項目，再送追加報價，客人會再到簽名頁同意追加費用。

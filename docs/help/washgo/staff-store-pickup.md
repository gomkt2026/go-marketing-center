# 回貨與待取件

## 待取件管理和回貨確認差在哪裡？

後台已整合成「待取件管理」：

- 待自取：客人要來門市拿。
- 待送回：要指派司機送達。

手機 LINE 仍可用「回貨確認」處理單筆。舊的回貨確認網址會轉到待取件管理。

## 客人來店取件要怎麼完成？

1. 打開待取件管理的「待自取」。
2. 核對訂單與存放位置。
3. 交給客人並完成現場簽收。
4. 需要時再通知下一筆可取件的客人。

客人 LIFF 的自取說明頁沒有簽名鈕，簽名由櫃檯完成。

## 要派司機送回怎麼做？

在「待送回」分頁或「回貨派遣」：

1. 確認包裹數（品管或櫃檯輸入的 N 包）。
2. 指派司機與運費。
3. 司機會在「今日任務」看到送回站。

自取訂單不要送到回貨派遣；畫面若提示這是自取，請改回待自取分頁。

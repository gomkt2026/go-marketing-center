# 收件與受理

## 客人當面送洗要怎麼開始？

1. 打開後台「門市收件」。
2. 用電話或姓名找會員。
3. 確認姓名後建立送洗單。
4. 建立後進入收貨覆核，清點、拍照、定價。

查無會員可在同一頁快速建檔，不必先請客人自己用 LINE 註冊。

## 客人用 LINE 下的單，誰要按受理？

打開員工 LIFF「待接單」的受理分頁，或後台營運中心篩選草稿。

- 受理：到府單會進入待派遣；門市自送會進入待覆核。
- 拒絕：請在備註寫原因，客人會需要門市後續說明。

自助／Kiosk 單若客人還沒簽名，系統會擋覆核，請先請客人在現場簽完。

## 熟客要我們代叫司機到府取件怎麼做？

打開「櫃檯代叫取件」：

1. 找到會員與地址。
2. 確認運費試算與洗滌風險告知。
3. 送出後訂單進入待派遣，再去「派遣」指派司機。

## 外縣市貨運怎麼收？

收件時選擇貨運模式。衣物寄到店後，到「貨運進件」點收，再做一般清點與報價。不要當成司機到府取件來派工。

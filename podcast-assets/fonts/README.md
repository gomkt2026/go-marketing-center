# 思源黑體 TW（字幕用）

請從 Adobe 官方 release 分支下載 **Subset OTF / TW**：

- [SourceHanSansTW-Regular.otf](https://github.com/adobe-fonts/source-han-sans/tree/release/SubsetOTF/TW)
- [SourceHanSansTW-Bold.otf](https://github.com/adobe-fonts/source-han-sans/tree/release/SubsetOTF/TW)

放到這個目錄，檔名必須完全一致。渲染腳本與 Cursor Skill 都讀這裡，不要改用其他字體。

# 聲音複製(Voice Clone)錄音讀稿

給訪談來賓錄製聲音樣本用。照下面的方式錄,ElevenLabs Instant Voice Clone 的相似度會高很多。

## 錄音要點(比念什麼更重要)

- **長度**:總共 1~3 分鐘最理想,低於 1 分鐘相似度會明顯下降
- **環境**:安靜房間,關冷氣風扇,離牆遠一點(避免回音);手機錄音就夠,嘴巴離麥克風約 15~20 公分
- **只有一個人的聲音**:不能有背景音樂、電視聲、別人講話
- **用「平常聊天」的方式念**:Clone 出來的聲音會複製你錄音時的講話狀態——因為要上 Podcast 聊天,所以請用跟朋友聊天的語氣錄,不要像朗讀課文或演講
- **自然就好,吃螺絲不用重來**:小小的停頓、笑聲、「嗯」「欸」反而讓聲音更像本人
- **語速和音量保持平常的樣子**,不要刻意放慢或提高

## 讀稿(約 2 分鐘,直接照念,語氣自然)

> 哈囉,大家好,我是ˍˍˍ。今天天氣還不錯,想說來錄一段聲音,跟大家隨便聊聊。
>
> 我平常的工作喔,其實說起來滿有趣的。每天早上大概七點半起床,先泡一杯咖啡,然後看一下今天的行程。有時候忙起來,一天要跑三、四個地方,晚上回到家都快九點了。不過說真的,做久了也就習慣了,而且每次把事情做好、客人跟你說謝謝的時候,那種感覺真的很不錯。
>
> 欸,對了,跟你們講一件好笑的事。上禮拜我遇到一個客人,他問我說:「這個真的有辦法處理嗎?」我跟他說:「放心啦,我做這行二十年了,什麼場面沒見過!」結果他就笑了,說我講話很有自信。哈哈,其實我心裡也是會緊張啦,只是經驗多了,知道遇到問題要一步一步來,急也沒有用。
>
> 如果要我給年輕人一個建議,我會說:不管做哪一行,基本功最重要。你可以慢,但是不能隨便。因為客人可能不懂技術,但他感覺得出來你有沒有用心。
>
> 嗯…大概就是這樣吧!希望之後有機會,可以跟大家分享更多的故事。謝謝大家,掰掰!

## 為什麼是這份稿

這份稿刻意涵蓋了 Clone 需要的聲音特徵:

| 段落 | 目的 |
|------|------|
| 開頭打招呼 | 自然的開場語氣、自我介紹的節奏 |
| 描述日常 | 平穩的敘事語氣(訪談回答的主體) |
| 好笑的事 + 引述對話 | 情緒起伏、模仿別人講話的音調變化、笑聲 |
| 給年輕人的建議 | 認真、放慢的語氣(講重點時的樣子) |
| 結尾道別 | 收尾的語調下沉 |

來賓可以把「ˍˍˍ」換成自己的名字,內容跟自己經歷不符也沒關係——**Clone 學的是聲音,不是內容**。如果來賓願意即興發揮、用自己的話講類似的內容,效果會比照稿念更好。

# 匠城出任務：網頁遊戲部署說明

一個班 90 秒的 3D 城市跑單小遊戲，一局裡會玩到 TaskGo 報修派工、Homigo 送鑰匙交屋、Washgo 衣物收送。整個遊戲是純靜態檔案，不需要後端，放到任何網站空間都能跑。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 遊戲本體（含社群分享預覽設定） |
| `vendor/three.min.js` | 3D 引擎 three.js r128（MIT 授權，已附在同一個資料夾，不依賴外部 CDN） |
| `og-image.jpg` | 分享到 FB / LINE / Threads 時顯示的預覽圖（1200×630） |
| `icon.svg`、`icon-192.png`、`icon-512.png`、`apple-touch-icon.png` | 網頁圖示與「加入主畫面」圖示 |
| `manifest.webmanifest` | 讓手機可以把遊戲加入主畫面，以全螢幕開啟 |

## 放進 GO 行銷中心（go-marketing-center）

1. 把整個 `game` 資料夾複製到專案的 `public/game/`。
2. 目前網址設定為 `https://go-marketing-center.pages.dev/game/`（Cloudflare Pages 的預設網域）。之後如果綁了自己的網域，請改兩個地方：
   - `index.html` 開頭的 `og:url`、`og:image`、`twitter:image`、`canonical`（搜尋 `go-marketing-center.pages.dev/game/` 全部取代）
   - `index.html` 裡的 `CONFIG.siteUrl`（同一個搜尋就會找到）
3. `git push`，Cloudflare Pages 會自動部署。
4. 打開 `https://你的網域/game/` 確認看到遊戲標題畫面。
   - Vite 會把 `public/` 原封不動複製到 `dist/`，靜態檔案優先於 `_redirects` 裡的 `/* /index.html 200`，正常情況下不用改設定。
   - 如果打開卻看到行銷中心的 React 頁面，請確認網址最後有斜線 `/game/`。

## 分享前的檢查

- **預覽圖**：部署後，用 [Facebook 分享偵錯工具](https://developers.facebook.com/tools/debug/) 貼上遊戲網址，按「再次抓取」，確認出現標題和預覽圖。LINE 會快取預覽，改過圖後要等一段時間才會更新。
- **手機實測**：分別從 LINE、FB、IG 的內建瀏覽器打開連結玩一局，確認有聲音、搖桿順暢。

## 遊戲內的分享機制

- **成績圖**：結算畫面按「分享成績」，會產生一張 1080×1350 的成績圖（IG 直式尺寸），包含當局畫面、營收、師傅等級與三品牌成績。手機可長按圖片存到相簿；支援系統分享的手機會直接跳出分享選單。
- **挑戰連結**：分享出去的連結會帶分數，例如 `https://go-marketing-center.pages.dev/game/?s=18420`。朋友打開後，標題畫面會顯示「朋友賺了 NT$18,420，換你來挑戰」，結算時也會告訴他有沒有贏。
- **品牌導流**：結算畫面有三個品牌的連結（TaskGo 免費試用、Homigo 官網、Washgo 官網），網址在 `index.html` 的 `CONFIG.links` 修改。

## 追蹤成效（選用）

在 `index.html` 的 `<head>` 貼上 GA4 或 Meta Pixel 追蹤碼（有註解標示位置），遊戲會自動送出下列事件：

| 事件 | 時機 | 附帶資料 |
|---|---|---|
| `game_start` | 按下開始上工 | 是否從挑戰連結進來 |
| `game_end` | 一局結束 | 分數、等級、三品牌完成數 |
| `share_open` / `share_native` / `share_copy` / `share_download` | 各種分享動作 | 分數 |
| `brand_click` | 點品牌連結 | 品牌名稱 |

沒有貼追蹤碼時，這些事件只會寫進 `window.dataLayer`，不影響遊戲。

## 車庫與成長系統（v3 新增）

- **匠幣**：每跑完一班，營收每 NT$100 換 1 枚匠幣；連續上工、每日任務、成就另有加碼。
- **車庫**：7 台機車、8 套服裝。一般造型用匠幣解鎖，「金色傳說」「金安全帽」「老闆西裝」只能靠成就拿到。
- **每日任務**：每天輪替一個任務，完成可領匠幣。
- **急件**：遊戲中偶爾出現金色外框的急件，時間較短、報酬 ×1.8。
- 匠幣、造型、成就都存在玩家自己的瀏覽器（localStorage），換手機或清除瀏覽資料會重來。
- 追蹤事件新增：`garage_open`、`item_unlock`、`item_equip`、`achievement`。

## LINE / IG 內建瀏覽器與一鍵分享（v4 新增）

- **分享面板**：Threads、Facebook、LINE 都是一鍵分享（會帶成績文字和挑戰連結）；IG 沒有開放網頁直接發文，按「IG 限動」會自動複製挑戰連結，並提示「存圖 → 開限動 → 加連結貼紙」。在一般手機瀏覽器會直接跳出系統分享選單。
- **導流改成加 LINE 好友**：手機上 Homigo、Washgo 的連結會直接開啟 LINE 官方帳號（@933pdush、@washgo）加好友；電腦上仍連到官網。
- **防誤觸**：遊戲中拖曳不會讓頁面上下捲動或回彈。
- **自動降畫質**：開局 3.5 秒內偵測到手機跑不動，會自動降低解析度和陰影品質。
- **跨 App 帶進度**：車庫 → 成就頁 → 「複製進度連結」，在另一個 App 或瀏覽器打開，匠幣、造型、成就都會帶過去。
- 追蹤事件新增：`share_threads`、`share_fb`、`share_line`、`share_ig`、`progress_export`、`progress_import`、`quality_low`；`game_start` 會附帶 `env`（line / instagram / threads / facebook / mobile / desktop），可以看出玩家從哪個 App 進來。

## 小中大三張地圖與排行榜（v5 新增）

| 地圖 | 大小 | 一班 | 解鎖條件 | 特色 |
|---|---|---|---|---|
| 小地圖 | 3×3 街區 | 90 秒 | 一開始就有 | 教學路線、1 間洗衣中心 |
| 中地圖 | 4×4 街區 | 120 秒 | 累積獲得 300 匠幣 | 多了 TaskGo 智慧工地（塔吊會轉） |
| 大地圖 | 5×5 街區 | 150 秒 | 累積獲得 500 匠幣 | 2 間洗衣中心、3 個工地 |

- 解鎖看「累積獲得」的匠幣，花掉買造型不會讓地圖被鎖回去。
- 挑戰連結會帶地圖（`?s=分數&m=s|m|l`），朋友就算還沒解鎖，也能直接玩那張地圖接受挑戰。
- 最佳紀錄、師傅等級門檻、排行榜都按地圖分開。

### 線上排行榜（GO 行銷中心版）

排行榜接行銷中心現有的賽季系統，API 在 `CONFIG.api`（`/api/public/game`），資料表 migration 是 `db/migrations/056`、`058`、`059`（缺表時 API 也會自動補建）。

| API | 用途 |
|---|---|
| `POST /start` | 開局拿憑證（帶 `map`），成績以開局時的地圖為準 |
| `POST /heartbeat` | 遊玩中每 10 秒回報，算「正在上工」與遊玩時長 |
| `POST /submit` | 結算送分：暱稱、手機、同意勾選，加上本局統計 |
| `GET /leaderboard?map=&scope=all` | 依地圖的本季榜（沒賽季就是總榜），`scope=all` 看總榜 |
| `GET /season`、`GET /stats` | 進行中的賽季與獎品地圖；正在上工、累計遊玩、最常上工 |
| `GET/POST /referral` | 邀請朋友解鎖台灣地圖 |

- 每支手機在每張地圖只列最佳成績。賽季獎品只看後台「設定 → 遊戲排行榜」選的**獎品地圖**（預設小地圖）。
- 防灌分：開局憑證、依地圖的最短遊戲時間、分數要和工單數、急件、三連單、臨檢／垃圾車／地標加分、罰單扣分對得上。
- 取消不當玩家資格、標記得獎者都在後台操作。
- 還沒部署後端時，遊戲會自動改成只顯示本機最佳紀錄，不會出錯。

## 隱藏版台灣地圖（v6 新增）

- **地圖**：9×9 格排成台灣島，四周是海、中央山脈（含玉山）隔開東西兩側；台北（地標大樓）、台中（Homigo 代管中心）、高雄（TaskGo 工務所、港口貨輪），另有宜蘭、花蓮、台東、墾丁。一班 180 秒，三間洗衣中心，只能在陸地和沿岸道路上騎。
- **高鐵站**：台北、台中、高雄各一站，騎進站會自動搭到「離最急工單最近」的那一站。
- **TaskGo 服務進度看板**：內容在 `index.html` 的 `CONFIG.regions` 修改，例如 `{city:'台北',status:'10 月中團隊到位',live:false}`。`live:true` 顯示橘色、`false` 顯示深藍色。
- **解鎖方式（混合制）**：
  1. 標題畫面「台灣地圖」卡片 → 分享解鎖 → 按 Threads / Facebook / LINE / 複製連結任一個，立刻送 1 次體驗。
  2. 朋友從分享出去的連結（`?ref=邀請碼`）進來、玩完一班，遊戲會回報給 `/api/game/referral`；邀請人回到標題時自動檢查，累積 1 位朋友就永久解鎖。
  3. 結算畫面的成績分享連結也帶邀請碼，一樣算數。
- 沒有部署推薦 API 時，無法確認朋友有沒有來玩，所以每次分享都會再送 1 次體驗，不會卡關。
- 追蹤事件新增：`invite_open`、`invite_share`、`referral_done`、`taiwan_unlock`、`map_select`、`board_open`、`score_submit`。

## 天氣、隨機事件、名場面與台灣地標（v7 新增）

**天氣**（每一班隨機，第一次玩固定晴天）
| 天氣 | 機率 | 影響 |
|---|---|---|
| 晴天 | 45% | 正常 |
| 雨天 | 27% | 雨絲、路滑轉彎會甩尾；穿「機車雨衣」抓地力變好 |
| 強風 | 18% | 陣風會把機車往旁邊推、落葉亂飛 |
| 下雪 | 10% | 雪花、地面變白、最滑，會跳「高雄下雪了？！」 |

**隨機事件**（每一班 2～4 件，同一件事一班最多一次）
- 野狗追車：3 隻土狗從後面追，被追到會被包圍、動彈不得 1.6 秒。
- 忘記帶工具：報修到現場時有機率發現扳手沒帶，要先回 TaskGo 工務所拿工具箱。
- 警察臨檢：路口臨檢站，停車受檢 +NT$200；直接闖過去罰單 -NT$600。警察有禮貌、只是提醒。
- 電量／油量見底：速度只剩四成還會冒煙，要去換電站（電動小白）或加油站。畫面不使用任何機車品牌名稱。
- 垃圾車：播《給愛麗絲》，後面一群提垃圾袋的鄰居在追；陪著騎 3 秒 +NT$300。
- 手搖飲：路上隨機出現，喝了全速衝刺 6 秒。

**今日名場面**：被狗包圍、被開罰單、甩尾、下雪、在地標打卡等瞬間會自動拉近截圖，結算時顯示，點一下就產生 1080×1350 的「名場面」圖卡，可以一鍵分享。

**台灣地標**（台灣地圖）：台北 101、龜山島、太魯閣、台中歌劇院、日月潭、阿里山（神木＋小火車）、安平古堡、高雄愛河（愛之船）、鵝鑾鼻燈塔。騎經地標自動「GPS 打卡」+NT$100，收進車庫成就頁的「地標圖鑑」。地標是示意的低多邊形造型，名稱是地名標示。

**新成就**：土狗的好朋友、守法好市民、雪地師傅、手搖飲成癮、環島打卡王。

追蹤事件新增：`event`（type：dogs / police / battery / garbage / tools）、`moment`、`moment_share_open`、`checkin`；`game_start` 附帶 `weather`。

## 多國語系

遊戲支援 **中文、English、日本語、Tiếng Việt、Bahasa Indonesia**。計分、賽季、心跳、邀請解鎖和瀏覽器裡的匠幣進度都跟語言無關。

- **已經玩過的人**：瀏覽器裡已有進度時，維持中文，直到自己按標題畫面右上角的 🌐 換語言。
- **新玩家**：依手機語言自動切換（日文、越南文、印尼文或馬來文）。其他語言在台灣時區預設中文，不在台灣則預設英文。
- **指定語言的連結**：網址加 `?lang=en`、`?lang=ja`、`?lang=vi`、`?lang=id`、`?lang=zh`。
- 翻譯檔在 `jiangcheng-game_多國語系/i18n-source/`。中文原文是鍵，改完後要重新寫進 `public/game/index.html` 的 `I18N_DATA` 區塊。
- `game_start` 附帶 `lang`。

## 隨機突發路況

每一班會在地圖上隨機出現突發路況（小、中、大、台灣地圖都有），大約每 10～16 秒一個，同時最多 2 個，同一種一班只出現一次，開局 12 秒內和結束前 10 秒不會出現。共 21 種：

| 類型 | 路況 |
|---|---|
| 整條封路，要繞路 | 選舉造勢車隊、住宅火災、前方施工、雞群過馬路、街頭拍攝、廟會遶境、臨時市集、倒樹事件 |
| 封半條路 | 貓咪卡在車底、貨車卸貨中、吊車作業、雙黃線臨停、公車故障 |
| 變慢 | 狗狗大逃家、外送大軍、學校放學（15:15 之後）、道路積水 |
| 會移動 | 救護車通行、婚禮車隊 |
| 天氣與路面 | 突然暴雨（晴天變雨天）、巨大坑洞 |

- 小獎勵：攔下逃家的狗 +NT$200、禮讓救護車 +NT$100（擋住 -NT$200）、跟婚禮車隊拿喜糖 +NT$66、經過遶境 +NT$88。這些加減分在遊戲內計入營收，送分仍走原本的 `/submit`。
- 車庫 → 成就頁有「路況圖鑑」（存在 `jiangcheng-profile-v1` 的 `incSeen`），新成就「路況老司機」「熱心師傅」。
- 選舉車隊的候選人是虛構的「阿匠」。
- 追蹤事件新增 `incident`（type、map、wx）。
- 路況名場面會等師傅騎到路況 12 公尺內才拍，鏡頭偏向路況，照片裡看得到是什麼路況。

## 路況名場面 Threads 分享活動

- 設定在 `index.html` 的 `CONFIG.promo`：主題標籤、`@inforcraft_`、活動貼文網址 `post`、起訖時間。只在中文介面、活動期間顯示，時間到自動消失。
- 開始畫面有活動橫幅，結算畫面的「今日名場面」底下有參加說明；分享名場面時，Threads 預填文字會帶 `#匠城路況 @inforcraft_`。
- 活動辦法：`/legal/game-threads/`。
- 追蹤事件新增 `promo_open`、`promo_post`。
